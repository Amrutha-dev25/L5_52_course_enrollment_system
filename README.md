Run the program from the repository directory:

```bash
python course_enrollment_system.py
```

The program runs a demonstration of course enrollment, course status, scholarship tuition calculation, student hashing, OTP generation, roster export, and registrar-token configuration. It does not require interactive input.

To configure the registrar token, set the `REGISTRAR_AUTH_TOKEN` environment variable before running the program. The program displays whether the token is configured, not its value.
